# Returns without a receipt

Policy RT-02, version 2. Owner: Store Support.

## Rules

- Without a receipt, staff first search the purchase history by the loyalty number or the payment card used.
- If the purchase is found, the standard return rules (RT-01) apply as if the customer had a receipt.
- If no purchase record is found, Harbor Goods offers **store credit only**, at the lowest selling price of the item in
  the last 60 days.
- A customer may make at most **three receiptless returns in a rolling 12-month period**. The point-of-sale system
  blocks the fourth and shows code RL-12.
- Receiptless returns above USD 150 need a store manager's approval.

## Identification

A government-issued photo ID is required for receiptless returns. Staff record only the ID type and the last four
characters of the ID number. Never photocopy or scan the ID.
